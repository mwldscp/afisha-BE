## Event Poster (backend сервиса Афиша мероприятий)

backend-часть Fullstack-приложения для просмотра и управления мероприятиями

Сервис предоставляет REST API для отображения списка событий с фильтрацией и поиском, а также выполняет CRUD-операции по созданию, изменению и удалению мероприятий

## Основной функционал

**Мероприятия:** вывод списка с пагинацией, фильтрацией (дата, категория) и поиском по названию

## Технологический стек

**Фреймворк:** NestJS
**Язык:** TypeScript
**База данных:** PostgreSQL
**ORM:** TypeORM
